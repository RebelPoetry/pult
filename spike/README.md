# Спайк Ф0 — 15 строк проверок

Без UI. Цель — таблица «работает / не работает / обход» (итоги — в `docs/05-DELTA-v0.4-spike.md` и `docs/06-DELTA-v0.5-spike-claude.md`; сводка и журналы прогонов в публичное дерево не входят). Не прошёл провайдер — откладывается он, не проект.
Правила: тратить минимум квоты (крошечные промпты, у Codex усилие low, у opencode только модели с `cost == 0`); работать только внутри `spike/`;
не читать и не печатать креды; все поднятые серверы и демоны гасить; службы launchd не загружать.
Песочницы для агентов: `sandbox-a`, `sandbox-b` — одноразовые git-репозитории.
