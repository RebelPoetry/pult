# Идеи Hermes в Пульте — решение лида (28.09.2026)

Основание: внешний разбор Hermes Agent (26.09, вне репозитория), спайк `09-DELTA-hermes-spike.md` (PR #7).
Владелец хочет взять у Hermes всё: память, самописные скиллы, управление с телефона, субагентов.

## Решение
Адаптер Hermes (провайдер №4 через ACP) сейчас **не строим**. Спайк показал, что он возможен, но главная ценность через ACP не доезжает
или стоит слишком дорого:
- `delegate_task` через ACP не работает: результат ребёнка не доставляется никогда;
- гейт разрешений — denylist регулярок, `rm файла`, `mv`, `truncate`, `> файл`, `git checkout -- .` идут без спроса;
- по умолчанию Hermes читает вход Claude Code из Keychain и токен GitHub через `gh`, лениво ставит пакеты и качает непинованный `tirith` —
  всё выключается конфигом, но каждый релиз может добавить новый источник (выпуски раз в неделю);
- провал хода отличим от успеха только по тексту реплики.
Возможности берём **нативно**, поверх уже работающих адаптеров `claude` и `codex` (и `opencode` в Ф1.5).

## Куда что встаёт
| Возможность | Как в Пульте | Где в роадмапе |
|---|---|---|
| Области разрешений «один раз / на сессию / всегда» + «никогда» | правила только в брокере Пульта, точное совпадение (провайдер, инструмент, нормализованный ввод) в пределах cwd/worktree; никогда по префиксу; жёсткий стоп-лист (rm/mv вне worktree, curl/wget/nc/ssh, git push, sudo, pipe в sh, перенаправления вне cwd); правило создаёт только человек (`pult perm approve --session\|--always`), `rules.json` 0600, `pult perm rules` со счётчиками, каждое авторешение в журнал как `how: 'rule'`; «никогда» сильнее «разрешить»; недоступный демон — по-прежнему отказ | начало Ф1.5; кнопки — Ф2 |
| Итоговая запись хода | `pult agent prompt --wait --format stream-json`, последняя строка `result` на КАЖДОМ исходе (коды 0–5), исход — из настоящего итога хода (инвариант 4), пустой «успех» — провал | конец Ф1.5, до cron в Ф6 |
| Самописные скиллы | `pult learn <сессия>`: модель читает журнал сессии по правилам `skill-creator` и пишет ЧЕРНОВИК `SKILL.md` в `PULT_HOME/proposals/`; человек смотрит дифф и принимает `pult learn accept <id>` → `.agents/skills/<имя>/` + симлинк для Claude (конвенция AGENTS.md); без человека в скиллы не пишется ничего | Ф5 (мини-сессия — тот же механизм «модель предлагает, человек применяет») |
| Общая память агентов | `PULT_HOME/memory/USER.md` и `memory/projects/<repo>.md`; подаётся только на чтение: `claude` — `--append-system-prompt`, `codex` — инструкции разработчика треда; запись только `pult memory add` или принятым предложением из `pult learn`; из реплик модели сама не пишется (иначе один агент внедряет инструкции другому) | Ф6, после замера пользы на неделе В5 |
| Телефон | Telegram-бот без LLM в цепочке: вопросы Inbox с кнопками «разрешить один раз» / «отказать», статус агентов, `/prompt` только в уже заведённую сессию; один chat_id, токен в `PULT_HOME/secrets` 0600 с тестом редакции, одноразовый nonce в кнопке, молчание — отказ, исходящие через страж страны и с отказом при плохом выходе | Ф6 без изменений |
| Субагенты | уже есть: инструмент `Agent` у Claude и `subAgentActivity` у Codex видны в `pult agent tree` | — |

## Ворота для адаптера Hermes
Требования к адаптеру на случай пересмотра — `09-DELTA-hermes-spike.md` §4 (окружение, конфиг, протокол). Пересматриваем, когда выполнено ВСЁ:
1. `delegate_task` доставляет результат через ACP (в `acp_adapter` появился потребитель `completion_queue`);
2. у гейта есть режим «спрашивать всё», или Пульт умеет ограничить Hermes песочницей, как Codex (`workspace-write`);
3. два релиза подряд не меняют набор выключателей чужих логинов и загрузок (`auth.adopt_external_logins`, `suppressed_sources`, `HERMES_DISABLE_LAZY_INSTALLS`, `security.tirith_enabled`).

## Попутно для самого Пульта
- **Соединения мимо туннеля.** Спайк видел у давно запущенного интерактивного `claude` поток к Anthropic через `en0` рядом с `utun10`:
  соединение, открытое до подъёма TUN, живёт вне туннеля, и проверка страны через `curl` его не видит. Для Пульта это значит: если VPN
  упал посреди хода, дочерний процесс переподключится напрямую. Страж проверяет выход только перед ходом. Лечится только выключателем
  трафика в самом VPN-клиенте (kill switch). В README Ф1 (В5) — строка об этом.
- **Подписка терминального `claude` — Team.** `claude auth status --json` → `subscriptionType: "team"`. Пульт и любой плагин тратят
  ту подписку, в которую залогинен терминальный `claude`; `pult doctor` показывает тип подписки (В5).
