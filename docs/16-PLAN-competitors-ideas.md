# Идеи Claude, Codex, OpenCode, ZCode и ещё 34 приложений в Пульте — решение лида (20.10.2026)

Источник: пять субагентов 20.10.2026, официальные доки, чейнджлоги и релизы 38 продуктов. Продукты из прошлых разборов
(Conductor, Superset, cmux, Warp, Zed, Kent, Orca, Pi, Hermes, sandcastle — планы 10–15) не повторяются.
Владелец 20.10 принял предложения ресёрча («обнови план с учётом предложений»); раскладка по релизам — решение лида.
Открыт один вопрос — телефон (№ 13), решить до старта Ф6. Страница ресёрча приватная — выводы в этом документе.

**Нумерация (решение владельца 20.10):** публикация — 0.3.0, а не 1.0.0 (0.x — норма ниши, 0.1.0 не годится: канал обновлений не ставит версию ниже стоящей 0.2.29). Релизы: 1.0.x → 0.3.x, 1.1 → 0.4, 1.2 → 0.5, 1.3 → 0.6. В планах 10–13 остались старые номера.

## Главное

- **Телефон — главный тренд.** Управление локальными агентами с телефона показывают девять продуктов: Codex Remote,
  Cursor (с 06.10), opencode 2.0 (QR-код и PWA), Claude Remote Control, Paseo, Happy, Nimbalyst, Qoder, ZCode. С телефона
  там не только разрешают, но и читают сессии, отвечают и заводят задачи. Наш Telegram-бот только для разрешений (Ф6) уже,
  чем у всех.
- **Экран «кто ждёт».** Claude Code (`claude agents`), Devin Desktop, Copilot app и Nimbalyst группируют сессии по
  состоянию и пишут под каждой одну строку «что сейчас». Дешёвый шаг до канбана Ф4.
- **Цель вместо хода.** `/goal` есть у Codex (вышел из беты), Kimi, Cursor, ZCode и Jean: агент сам гонит ход за ходом до
  проверяемого результата, с паузой и очередью целей на ночь.
- **У Пульта есть близнец — [Paseo](https://github.com/getpaseo/paseo):** демон плюс клиенты для десктопа, телефона, веба
  и CLI над семью агентами, 21,5 тыс. звёзд, Apache-2.0, 0.12.0 от 19.10. Перед публикацией сформулировать отличия:
  общий Inbox с правилами, страж страны и прокси, подписанные обновления, флоу.
- **Шеринг сессий уходит:** opencode убрал `/share` в 2.0.30, Amp закрыл публичные треды. Не строим.

  родного `/goal`. Приёмка Ф3 дополняется: цель хотя бы раз дошла до зелёной проверки сама, без реплик человека.
- **Ф4:** во вкладку «Проверки» — тумблеры «чинить CI и замечания» и «смёржить, когда зелёный», авто-архив после мёржа,

  «перепаковать коммиты» (№ 17).
- **Ф6:** телефон по решению № 13; уведомления по срочности (№ 14); события как триггеры (№ 20); история и детали

  выбран бот; при PWA — откладывается.
- **Порядок резки при нехватке времени:** 0.6 целиком → «перепаковать коммиты» (№ 17) → подсказка реплики (№ 5) →

- **Страница v0.6** переписывается в v0.7 на старте Ф3 вместе с планами 13–16, как решено в плане 13.

## Открытый вопрос — телефон (№ 13)

Решить до старта Ф6.

- **PWA (рекомендация лида).** Веб-окно демона, которое ставится на телефон как приложение; вход по QR-коду. Видно всё:
  сессии, ответы, разрешения, новые задачи. Доступ — только через Tailscale (демон слушает tailnet-адрес, токен из QR,
  без своего сервера и без чужого relay). Минус — демон впервые выходит за `localhost`: нужен отдельный разбор
  безопасности. Оценка 2–3 недели.
- **Telegram-бот (план 10).** Только разрешения и `/prompt` в существующую сессию, без LLM в цепочке. Проще и безопаснее,
  но уже, чем у всех девяти конкурентов. Оценка ~1 неделя.

## Не берём

- **Облачные сессии и перенос в облако** (claude.ai/code, Codex cloud, Cursor, Devin) — Пульт локальный по замыслу.
- **Управление компьютером** (Claude, Codex, Kiro, Factory) — большой риск, мало пользы для кода.
- **Публичные ссылки на сессии** — opencode и Amp их уже закрыли.
- **Несколько аккаунтов одного провайдера** и перенос сессии между ними (opencode, agent-deck) — лимиты Pro и Max
  рассчитаны на обычное личное использование, удар придётся по аккаунту.
- **Docker-песочница** (JetBrains Air, agent-deck) — пока хватает worktree и режимов подтверждения.
- **Linear, Jira и другие трекеры** (Emdash) — личному инструменту хватит GitHub Issues из Ф4.
